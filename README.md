## 👋 About Me:

🤖 **AI Engineer** building production LLM systems — multi-agent workflows, RAG pipelines, and voice agents  
🧠 Working daily with **LangGraph, LangChain, LlamaIndex, AutoGen** and **MCP** servers  
📚 Deep in **RAG**: hybrid retrieval, embeddings, reranking, and the evaluation that proves it works  
🎙️ Real-time **voice AI** with LiveKit, Whisper and ElevenLabs at sub-500ms latency
